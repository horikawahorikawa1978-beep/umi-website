Umi公式サイト GitHub 安全更新版

【最重要】
GitHub上の現在のファイルを削除してから入れ直さないでください。
このZIPを展開し、同名ファイルを上書きアップロードしてください。

【安全な手順】
1. GitHubの現在のリポジトリをZIPでバックアップ（Code → Download ZIP）
2. このZIPをPCで展開
3. 展開した「中身」だけをGitHubリポジトリのルートへアップロード
4. 同名ファイルは上書き、新規の contact.html は追加
5. Commit changes
6. 公開サイトで HOME / ABOUT / PHILOSOPHY / BRAND / COMPANY / CONTACT を確認
7. CONTACTフォームは自分のメールアドレスで1回だけテスト送信

【今回の確認済み内容】
・HOME / ABOUT / PHILOSOPHY / BRAND / COMPANY のヘッダー/フッター CONTACT → contact.html に統一
・contact.html → Formspree (mnpakvyg) 設定済み
・COMPANYページ内のメールアドレス表示は mailto:info@umi-beauty.com のまま（意図的）
・style.css はページ別CSSを含む統合済み版
・必要画像とロゴを同梱

【戻したい場合】
手順1で保存したバックアップZIPの内容をGitHubへ戻せば復旧できます。
